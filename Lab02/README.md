# Lab 02 – Image Processing Fundamentals

## Overview
This project explored the fundamentals of digital image processing. Images were represented as numerical arrays, and common processing techniques such as brightness adjustment, contrast enhancement, convolution filtering, histogram equalization, and edge detection were applied.

## Skills Demonstrated
- Digital image representation
- Image enhancement
- Convolution filters
- Histogram equalization
- Edge detection

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib

## Files
- `L02_Patin_Morris_ITAI1378.ipynb`

## Learning Outcome
This lab demonstrated how mathematical operations affect digital images and provided the foundation for later computer vision and deep learning projects.
