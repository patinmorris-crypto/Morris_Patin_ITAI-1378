# Lab 04 – CNN Image Classification

## Overview
This project introduced convolutional neural networks (CNNs) through an image classification task involving Chihuahua and Muffin images. The notebook demonstrated how CNNs automatically learn visual features to classify similar-looking objects.

## Skills Demonstrated
- Deep Learning
- CNN Architecture
- Image Classification
- Model Evaluation

## Technologies Used
- TensorFlow
- Keras
- Python

## Files
- `L04_Morris_Patin_ITAI1378.ipynb`

## Learning Outcome
This project demonstrated the advantages of convolutional neural networks over traditional neural networks for computer vision tasks.
